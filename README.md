# FileCleaner
Находит дубликаты, старые и временные файлы, ищет документы и изображения по формату, названию или словам внутри поддерживаемых файлов.  Удобные фильтры и массовый выбор помогут разобрать тысячи файлов. Что убрать — решаешь сам: перемещение в Корзину только после подтверждения.  Для Windows. Установка не нужна.
